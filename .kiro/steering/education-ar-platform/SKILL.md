# 教育AR创作平台 - 开发指南

## 产品定位
零门槛AR内容创作平台，面向教育场景（教师课件、学生创作、学校运营）。核心能力：拖拽式场景搭建、可视化逻辑编排、多模态交互（手势/语音）、多人协作、一键导出AR应用。拓展场景：工业展示、医疗科普、文旅导览、多人游戏。

## 技术栈
- Vue 3 + TypeScript + Element Plus + SCSS
- WordPress REST API（新闻模块）
- 响应式：桌面(1200px+) / 平板(768-1199px) / 移动(<768px)
- 设备：Rokid AR Studio、iPad、网页端、手机端

## WordPress 新闻 API

| 接口 | 方法 | 说明 |
|------|------|------|
| `/wp-json/wp/v2/posts` | GET | 文章列表 |
| `/wp-json/wp/v2/categories` | GET | 分类列表 |
| `/wp-json/wp/v2/posts/{id}` | GET | 文章详情 |

分类：官方新闻、教育AR行业动态、校园应用案例、平台更新公告

## 登录模态窗口

使用 `el-dialog` 组件，居中+遮罩，ESC/点击遮罩可关闭，移动端全屏。

触发：导航栏"登录"按钮、Hero区"立即开始创作"、CTA区"立即登录"

内容：Logo + 用户名/密码表单 + 记住我 + 忘记密码链接 + 登录按钮 + 关闭按钮
